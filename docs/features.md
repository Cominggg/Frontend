# 기능 명세 요약 (v1.5)

## 우선순위

| 등급 | 의미 | 목표 |
|------|------|------|
| P0 | MVP 핵심 | v1.0 |
| P1 | 주요 기능 | v1.1 |
| P2 | 부가 기능 | v2.0~ |

## 기능 목록

### 회원 관리

| ID | 기능 | 우선순위 |
|----|------|----------|
| AUTH-01 | OAuth 소셜 로그인 (Google/Kakao) | P0 |
| AUTH-02 | 프로필 조회·수정 (이미지 jpg·png·webp, max 5MB) | P1 |
| AUTH-03 | 회원 탈퇴 | P1 |

### 아티스트

| ID | 기능 | 우선순위 |
|----|------|----------|
| ART-01 | 목록 조회 (이름·장르 필터, 페이지네이션 25건/페이지) | P0 |
| ART-02 | 상세 조회 (프로필·멤버 구성·데뷔일, MusicBrainz url-rels 링크, D-day 카운트다운, 디스코그래피 섹션) | P0 |
| ART-03 | 내한 공연 내역 (2020년~, 전체·예정·과거 탭 구분) | P0 |
| ART-04 | 관심 아티스트 팔로우·언팔로우 | P0 |
| ART-05 | 게시판 (운영 리소스 이슈 — 론칭 후 도입 권고) | P2 |
| ART-06 | 예정 내한 공연 있는 아티스트에 'Coming' 배지 표시 | P1 |

### 공연

| ID | 기능 | 우선순위 |
|----|------|----------|
| CON-01 | 공연 목록 (시작일 오름차순) | P0 |
| CON-02 | 공연 상세 (prfstate 배지, 예매처 링크, KOPIS 일별 갱신) | P0 |
| CON-03 | 인기 공연 (조회수 기반, 홈 노출 4건(1행)) | P1 |
| CON-04 | 관심 아티스트 예정 공연 필터 | P0 |
| CON-05 | 셋리스트 조회 (setlist.fm, 공연 완료 후) | P2 |
| CON-06 | 공연 상태 자동 갱신 (KOPIS updatedate 감지) | P1 |
| CON-07 | 공연 상세 데이터 없음 Empty View (404 시 EmptyState 컴포넌트 표시, "공연 정보가 존재하지 않습니다") | P0 |

| CAL-02 | 내 캘린더 공연 추가·제거 | P0 |

### 마이페이지

| ID | 기능 | 우선순위 |
|----|------|----------|
| MY-01 | 공연 히스토리 ('다녀온 공연' 탭, 페이지네이션 10건/페이지) | P1 |
| MY-02 | 관심 아티스트 목록 조회·언팔로우 (마이페이지 탭) | P1 |

### 음악 발매

| ID | 기능 | 우선순위 |
|----|------|----------|
| REL-01 | 새 앨범·싱글·EP 조회 (홈 수평 스크롤, ALBUM/SINGLE/EP 배지, 발매일 최신순) | P1 |
| REL-02 | 릴리즈 상세 조회 (트랙리스트·크레딧·커버·소개, `/releases/:id`) | P2 |
| REL-03 | 음악 전체 목록 조회 (`/releases`, 아티스트·타입 필터(ALBUM/SINGLE/EP/기타), 발매일 최신순, 홈 "전체 보기" + 상단 "음악" 탭 진입) | P2 |

### 데이터 문의

| ID | 기능 | 우선순위 |
|----|------|----------|
| INQ-01 | 공연 정보 문의 (concert_id 자동 주입, 유형 CONCERT 고정) | P1 |
| INQ-02 | 아티스트 정보 문의 (artist_id 자동 주입, 유형 ARTIST 고정) | P1 |
| INQ-03 | 셋리스트 정보 문의 (concert_id 자동 주입, 유형 SETLIST 고정) | P1 |
| INQ-04 | 내 문의 내역 조회 (마이페이지 탭, 처리 결과·반려 사유 확인) | P1 |

### 관리자 (/admin, ROLE_ADMIN)

|----|------|----------|
| ADM-01 | 아티스트 수동 등록·수정 | P0 |

| ADM-03 | 공연 수동 등록·수정 | P1 |

## 라우트 구조

| 경로 | 기능 | 인증 |
|------|------|------|
| `/` | 홈 (인기 공연) | 불필요 |
| `/artists` | 아티스트 목록 | 불필요 |
| `/artists/:id` | 아티스트 상세 | 불필요 |
| `/concerts` | 공연 목록 | 불필요 |
| `/concerts/:id` | 공연 상세 | 불필요 |
| `/releases` | 음악 목록 (REL-03) | 불필요 |
| `/releases/:id` | 릴리즈 상세 (REL-02) | 불필요 |
| `/calendar` | 캘린더 | 일부 필요 |
| `/my` | 마이페이지 | 필요 |
| `/admin` | 관리자 대시보드 | ADMIN |
